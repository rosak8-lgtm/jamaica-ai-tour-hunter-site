# JAMAICA: независимый Oracle-импорт каждые 5 минут

## Актуальный статус, 21 ноября 2026
По предоставленному журналу начальное автономное развёртывание **прошло успешно**: `JAMAICA_ORACLE_INDEPENDENT_5MIN_PUBLISHER_COMPLETE`, активен таймер `jamaica-oracle-catalog-5min.timer`, `Linger=yes`, старый таймер Lenovo отключён.

Для нового расширенного поиска по другим направлениям нужно **однократно** обновить код уже установленного publisher:
```bash
cd "$HOME/Загрузки/JAMAICA_WEB_LIVE_BRIDGE_20261120"
git pull --ff-only
bash scripts/upgrade_oracle_catalog_on_server_once.sh
```
Это разовая операция SSH-администрирования, не выполнение расписания на Lenovo. После неё серверный publisher использует файлы экспортёра в своём GitHub-клоне. Теперь Oracle автономно проверяет основные Иркутские направления каждые пять минут, Китай и Вьетнам как приоритет, а прочие страны с отметкой туристического каталога — по 8 направлений в цикле. При обнаружении доступного прайс-листа из Иркутска страна добавляется к постоянной очереди. Пока действующий серверный процесс не обновлён этим способом, он выполняет прежнюю выборку.


**Назначение:** полностью исключить Lenovo из регулярного обновления туристического каталога. После однократного развёртывания Oracle самостоятельно запускает проверку источника, публикует в GitHub Pages только публичные безопасные данные и продолжает работу при выключенном Lenovo.

## Схема

```text
Oracle Ubuntu (автономный сервер)
    jamaica-oracle-catalog-5min.timer (systemd user, Linger=yes)
        каждые 5 минут
            flock (запрет перекрывающихся запусков)
            scripts/oracle_site_publisher.py
                ↓ авторизованный GET API прайс-листов
                ↓ проверка страны, отеля, номера, даты и рублёвой цены
                ↓ допустимая публичная копия tour-previews.json
                ↓ публикация только если данные изменились
                  или спустя 30 минут требуется обновить отметку времени
                git push deploy key → main
                    ↓ GitHub Pages (автопубликация)
                        ↓ Jamaica website
                            каждые 5 минут / возврат в вкладку
```

Серверный ключ `~/.ssh/jamaica_catalog_deploy_ed25519` имеет права записи **только в репозиторий JAMAICA**, а не доступ ко всему аккаунту. Приватная половина остаётся на Oracle. GitHub SSH host key сверяется с опубликованным GitHub отпечатком Ed25519. Данные клиента, банковских карт и пароли оператора НЕ копируются и НЕ публикуются. Секреты поставщика читаются из существующего приватного файла **на Oracle**, который использовался ранее при ручном импорте.

## Однократное подключение

Первый раз можно выполнить команду с Lenovo, потому что на нём уже настроены SSH-ключ до Oracle и авторизация `gh` для назначения **деплой-ключа только нужному репозиторию**:

```bash
cd "$HOME/Загрузки/JAMAICA_WEB_LIVE_BRIDGE_20261120"
git pull --ff-only
bash scripts/deploy_oracle_5min_from_lenovo_once.sh
```

Сценарий создаёт приватный SSH-ключ НА Oracle, назначает только публичный ключ репозиторию через GitHub API, копирует безопасные программы НА Oracle и запускает первый серверный импорт. Лишь после подтверждения успеха отключает старый Lenovo timer `jamaica-tour-catalog-refresh.timer`. При сбое старый процесс не выключается, и итоговый статус не считается успешным.

Если у текущего `gh` нет прав администратора на управление Deploy keys, он выведет **только публичный ключ**, попросит вручную добавить его в GitHub → Settings → Deploy keys → Add deploy key → Allow write access, а затем повторить установщик. Личные GitHub-токены не передаются на сервер.

Таймер запускается от `ubuntu`. `loginctl` должен подтверждать `Linger=yes`, иначе установка прекращается. Это обязательный признак продолжения работы user-service после выхода SSH и выключения Lenovo.

## Частота и доступность

- **Каждые 5 минут:** попытка получить новые прайс-листы и обновить приватную безопасную выборку на Oracle.
- **Сразу при изменениях:** git push публичного каталога.
- **Если значения не изменились:** без лишнего git commit; не реже чем через 30 минут обновляется дата последней успешной публикации.
- **Каждые 5 минут / при возврате на вкладку:** открытая страница Jamaica запрашивает опубликованный каталог GitHub Pages.
- **Ежедневно, если возможно:** Oracle обновляет общий справочник стран/отелей из публичного источника.
- При ошибках API, SSH, GitHub или проверок **прошлая проверенная публикация сохраняется**; таймер повторяет запрос на следующем цикле. Никакие отсутствующие цены, места и страны не выдумываются.

Периодичность источника 5 минут должна соответствовать ограничениям API Библио-Глобуса. Ранее подтверждённым допуском поддержки был 15-минутный мониторинг: перед долговременным использованием 5-минутного режима стоит подтвердить новый лимит с оператором.

## Что эта версия НЕ делает

Автоматический импорт прайс-листов не является автоматическим бронированием. Публичные суммы относятся к двум взрослым и к моменту выгрузки. До подписанного договора необходимы фактическая котировка, обе стороны перелёта и проверка гостиницы. После подписания повторный расчёт, далее платёж, далее третья проверка и только затем заявка у поставщика.

Эквайринг, проверяемая электронная подпись, клиентская авторизация и официальные полномочия на создание заявок должны быть подключены **отдельно**. Без них флаги `live_booking_enabled` и `payments_enabled` остаются `false`, несмотря на работающее обновление прайсов.

## Проверка сервера (не требует Lenovo)

На самом Oracle:

```bash
systemctl --user is-active jamaica-oracle-catalog-5min.timer
systemctl --user list-timers --all jamaica-oracle-catalog-5min.timer --no-pager
systemctl --user show jamaica-oracle-catalog-5min.service -p Result -p ExecMainStatus --no-pager
loginctl show-user ubuntu -p Linger --no-pager
journalctl --user -u jamaica-oracle-catalog-5min.service -n 30 --no-pager
```

Для автоматической проверки публикаций можно открыть историю коммитов и Actions репозитория. Само наличие этого скрипта в GitHub **не означает, что он уже установлен на Oracle**; живое состояние удостоверяется сообщением `JAMAICA_ORACLE_INDEPENDENT_5MIN_PUBLISHER_COMPLETE` установщика и статусом таймера на сервере.
