# JAMAICA — новые источники фото и рабочего гостиничного бронирования

Проверено 21.11.2026 по официальным страницам поставщиков. `0` в публичных `hotel-media-feed/index.json` и `hotel-open-media/index.json` означает, что **ни один из новых крупных коммерческих источников не активирован для текущего сайта**. Никакие тестовые фото и предварительные цены не следует выдавать за коммерчески разрешённое предложение или возможность купить тур.

## Сравнение альтернатив

| Источник | Фото и наполненность | Доступ | Главное ограничение | Приоритет |
|---|---|---|---|---|
| **Nuitée Connect / LiteAPI** | Hotel API `/v3.0/data/hotels` содержит `main_photo` и идентификаторы, `/data/hotel` — `hotelImages`, HD URL, подписи и `defaultImage`; отдельные room photos | Самостоятельная регистрация, бесплатный sandbox | Публичные права на фото рядом с чужими турпакетами требуют проверки; sandbox не производство; для продажи — live договор, поставщик бронирования и оплата | **1 — проверить сейчас** |

## Что реализовано для Nuitée

`scripts/nuitee_sandbox_hotel_probe.py` — один **читающий** запрос к `https://api.liteapi.travel/v3.0/data/hotels` с `X-API-Key`; по умолчанию Таиланд, Паттайя, до 10 гостиниц. Можно проверить `NUITEE_TEST_COUNTRY=CN` (Санья) и `VN` (Нячанг). Каждый запуск расходует один запрос. Тест возвращает только агрегированные числа гостиниц, главных фотографий, прочих URL и стран, без копирования изображений на Oracle и без публикации TEST результатов.

**Порядок:**

1. Открыть https://dashboard.liteapi.travel/ и самостоятельно зарегистрироваться; получить **sandbox API key**. Не помещать ключ в ChatGPT, GitHub, HTML, браузерную консоль, скриншоты или историю shell.
2. В существующем чистом клоне проекта `~/Загрузки/JAMAICA_HBX_SAFE_TEST` обновиться и выполнить:

```bash
(
set -Eeuo pipefail
umask 077
WORK="$HOME/Загрузки/JAMAICA_HBX_SAFE_TEST"
[[ -d "$WORK/.git" ]] || { echo "STOP_CLONE_NOT_FOUND"; exit 2; }
cd "$WORK"
git pull --ff-only
read -r -s -p "Nuitée SANDBOX API Key: " NUITEE_SANDBOX_API_KEY
printf '\n'
export NUITEE_SANDBOX_API_KEY NUITEE_MODE=SANDBOX
NUITEE_TEST_COUNTRY=TH python3 -B scripts/nuitee_sandbox_hotel_probe.py
unset NUITEE_SANDBOX_API_KEY
)
```

3. Допускается отправить **только** строки `JAMAICA_NUITEE_...`, без секретов и URL изображений.

**Проверка не заменяет коммерческого доступа.** Перед импортом фото в публичную JAMAICA требуется документально подтвердить, что разрешено использовать изображения стороннего гостиничного поставщика рядом с турами Библио-Глобуса и PEGAS, определить домены CDN и лицензию на hotlink, атрибуцию, истечение прав, частоту обновления, mapping гостиниц и разрешение на показ комнат. Не импортировать результаты sandbox. Для настоящей продажи нужна реальная цена и наличие, юридические условия продавца, полноценная авторизация поставщика, подтверждение заказа и платежи; тестовый /data/hotels — не бронирование.

## Ключевая архитектура для коммерческого результата

1. **Источник туров** (БГ/PEGAS) — только доказанные реальные маршруты, даты и предварительные суммы, без фиктивных цен и мест.
2. **Справочник недвижимости** — один внутренний ID JAMAICA, отдельные источниковые hotel IDs, независимое сопоставление по адресу/координатам и официальной идентичности. Совпадение имени или страны само по себе недостаточно.
3. **Фотографии** — внешний HTTPS CDN от допущенного поставщика с проверкой прав, срока, источника, авторства и фактического соответствия выбранному отелю. Oracle хранит только URL/метаданные.
4. **Реальная продажа** — отдельно: актуальная стоимость + подтверждение мест/рейсов, договор и разрешение на создание брони, платежный провайдер, подтверждённая бронь до выдачи покупателю. Ни один фото API этого не решает.

Промежуточный результат: увеличенный технический лимит до 60k предварительных позиций и поддержка внешних лицензионных фото уже есть. Ценность следующего шага — получить хотя бы **один** законно подключённый источник фото с точным идентификатором отеля и подтвердить показ в браузере на реальной гостинице. Без этого добавление новых пустых адаптеров не улучшит пользовательскую выдачу.
