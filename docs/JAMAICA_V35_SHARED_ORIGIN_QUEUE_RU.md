# V35 — общая очередь городов (staging)
Это первый серверный компонент, не рабочий поисковик и не разрешение публикации. Использует официальный registry schema jamaica.origin-registry.v1, не создаёт города/страны по догадке. SQLite обеспечивает атомарный выбор одного задания, сохранение состояния между запусками, глобальную паузу минимум 180 секунд и общий cooldown оператора. Приоритет Иркутска и трёх основных стран действует при равной давности; новые задания и давно не проверенные маршруты не голодают. После аварии активное задание не перехватывается автоматически: сначала необходимо подтвердить остановку владельца. 
До интеграции с действующим браузерным воркером необходимо проверить исходный приватный реестр, реальный интерфейс выбора города, общий lock всех потребителей BG, точные поля доказательств и публикацию по origin. Не запускает таймеры, не изменяет существующий каталог, не затрагивает PEGAS и Telegram. Не считать результат OBSERVED подтверждением наличия или продажи. Не публиковать базы SQLite, персональные данные и приватные квитанции в GitHub.
Проверка: python3 -B -m unittest -v backend.test_bg_origin_queue
