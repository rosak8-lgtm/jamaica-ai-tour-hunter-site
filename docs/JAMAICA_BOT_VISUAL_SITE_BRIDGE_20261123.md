# JAMAICA — передача визуального результата бота V183 в сайт

Дата: 23.11.2026. Режим: **read-only, без оплаты и бронирования**.

## Исправленная клиентская логика

Сайт продолжает показывать все исходные предварительные предложения в
13 странах (или больше, если реальный поставщик и город вылета дадут
дополнительные направления). Отдельный необязательный фильтр
«✈✈ ЛУЧШАЯ ЦЕНА + два рейса» показывает **только визуальные
результаты**, действительно наблюдавшиеся доверенным ботом менее
15 минут назад **для идентичной карточки**.

Визуальные доказательства никогда не добавляются в базовую цену и
никогда не меняют `bookable=false`, `quote_verified=false`,
`availability_verified=false`. Источник может за 15 минут изменить
наличие мест. Для настоящей продажи всё равно необходима проверка
поставщика по выбранному составу туристов, договор, юридическое лицо
продавца, подписанный заказ, разрешённый платёж и запись брони в API.

## Приватный канал (Oracle)

`scripts/bot_visual_sidecar.py` читает только файл
`~/.local/share/jamaica-oracle-catalog/private-bg-route-first-receipts.json`.
Файл должен быть создан **проверенным источником-браузером**, иметь
владельца текущего пользователя и режим `0600`.
Он никогда не загружается в GitHub или публичный JavaScript.

Структура будущего приватного источника:

```json
{
  "schema": "jamaica.bg-bot-private-receipts.v1",
  "records": [
    {
      "preview_id": "p_<24 hexadecimal characters>",
      "route": "<trusted BG browser route evidence object>",
      "flight": "<trusted BG browser selected-detail evidence object>"
    }
  ]
}
```

Это только описание контракта, **не готовый пример настоящего
доказательства**. Поля `route` и `flight` должны содержать
согласованные данные из одного сеанса браузера, настоящий клик по
строке маршрута с точной меткой `ЛУЧШАЯ ЦЕНА`, отдельные статусы
обоих рейсов и соответствие source price-list ID и отелю.
Проверяет `backend/bg_route_first_visual_gate.py`.

**Важно:** текущий бот V183 уже содержит методы `next_marker_window`,
`price_class`, `send_best_observed`, `send_ranked`,
`render_live`, `run_cycle` и `capture_bg_v148.js`, но из одного
журнала поиска этих методов нельзя достоверно установить формат
их возвращаемых данных. Приватный адаптер, который реально записывает
описанный контракт, пока не подключён. Не делайте ручную подстановку
`best_price_verified=true` и не синтезируйте события клика.

Публикатор `scripts/oracle_site_publisher.py`:

1. Читает 60 000 валидированных предварительных записей (в лимите).
2. Читает не более 1,5 МБ приватных owner-only receipts.
3. Проверяет route-first/самолёты и идентичность выбранного тура.
4. Отбрасывает неизвестные, старые и несвязанные подтверждения.
5. Публикует **только** очищенный `tour-visual-evidence.json`,
   максимум 300 ID, время наблюдения, два булевых статуса;
   без source price-list IDs, cookie, URL, паролей, PII и цен.
6. Обновляет этот JSON вместе с каталогом атомарно одним Git-коммитом;
   если доказательств нет, публикуется пустой список.

Если приватный файл недоступен или повреждён, публикация туров
продолжается, но в визуальном фильтре остаётся ноль предложений.

## Сайт

`scripts/visual-selection.js` принимает исключительно правильный
публичный формат `jamaica.visual-selection.v1` и дополнительно
исключает визуальное наблюдение старше 15 минут по времени браузера.
Фильтр необязателен: по умолчанию все страны остаются в выдаче.
Отсутствие доказательств не означает, что в стране нет туров.

## Состояние продаж

В `checkout-config.json` пока нет реквизитов продавца, авторизации,
подписания договора и платежного провайдера:
`live_booking_enabled=false`, `payments_enabled=false`.
Их нельзя включать на основании визуального совпадения.

## Запуск/тестирование на Lenovo

```bash
(
set -Eeuo pipefail
cd "$HOME/Загрузки/jamaica-ai-tour-hunter-site"
git pull --ff-only origin main
python3 -B -m unittest -q \
  backend.test_bot_visual_sidecar \
  backend.test_bg_route_first_visual_gate \
  backend.test_preview_quote_engine
node scripts/test-visual-selection.mjs
bash scripts/upgrade_oracle_catalog_on_server_once.sh
)
```

Последний скрипт — существующий установщик обновления каталогового
публикатора на Oracle. До выполнения проверяйте собственный доступ и
конфигурацию; не вводите секреты в чат. Обновление **не запускает
оплату и не отправляет письма/Telegram**.

Сведения о методах бота V183 подтверждены локальным аудитом
пользователя, но факт их **живого выполнения в общей с сайтом
маршрутной сессии не установлен**.
