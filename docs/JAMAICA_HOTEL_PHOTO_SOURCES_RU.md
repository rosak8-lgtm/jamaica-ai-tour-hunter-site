# JAMAICA — гостиничные фотографии без хранения на Oracle

## Что реально означает «внешняя ссылка»

Прямой URL в атрибуте `img.src` означает, что браузер посетителя запрашивает изображение с сервера правообладателя (Wikimedia, проверенный CDN). Oracle хранит лишь текст URL, имя автора и лицензию. **Это не освобождает от авторского права**: показ чужого фото на коммерческом сайте может требовать лицензии даже при hotlink.

Нельзя гарантировать 100% фото 11 000 гостиниц с абсолютно нулевыми юридическими рисками, но можно использовать несколько прозрачных режимов:

| Источник | Для карточки JAMAICA | Условия |
|---|---|---|
| **Wikimedia Commons (приоритет без договорных платежей)** | Да, только проверенные фотографии именно отеля | CC BY, CC BY-SA, CC0 или Public domain; ссылка на источник, автор, ссылка на лицензию; проверка иных прав |
| **Openverse** | В перспективе | Поиск открытых лицензий — не независимая проверка, что фото действительно относится к данному отелю или что лицензия правильная |
| **HBX / Hotelbeds Content API** | Да, после активации | LIVE доступ и договорно подтверждённые права; точный отельный ID |
| **Официальный сайт отеля** | Обычная ссылка на сайт или галерею — да | Право встраивать `img src` или копировать фотографии требует разрешения владельца либо лицензии; `og:image` не даёт таких прав |
| **Unsplash** | Только когда подтверждено, что изображён точный отель | Лицензия коммерческая, но надо соблюдать API guidelines, hotlink и атрибуцию |
| **Google Places Photos** | Возможен отдельный интеграционный режим | Платный официальный API, идентификаторы мест, требования атрибуции, ограничения кэширования; нельзя просто массово сохранять/перепубликовывать фото |

## Реализованный бесплатный адаптер Commons

`scripts/commons_open_hotel_media.py` получает только JSON-метаданные с **двух официальных API**: Wikidata item `Q...`, связанный с отелем, и Commons File description. Не скачивает фото, не анализирует похожие названия по поисковикам, не берёт пляж вместо отеля.

Разрешаются только фото с проверенной лицензией и **независимо подтверждённой** парой `JAMAICA hotel_id ↔ Wikidata QID`; страна сравнивается по Wikidata P17. Файл фото извлекается из Wikidata P18, а дополнительные фото можно указать только после ручной проверки, что они действительно показывают объект размещения, и документированной ссылки на доказательство. Права всегда проверяются у отдельного файла через Commons imageinfo/extmetadata (`Artist`, `LicenseShortName`, `LicenseUrl`).

Для большого набора результатов метаданные делятся на `hotel-open-media/index.json` + части по 200 гостиниц. И главная выдача туров, и галерея отеля загружают фото напрямую через Wikimedia Commons `Special:FilePath` с автором, ссылкой на оригинал и лицензию. Никаких фотографий из Wikimedia на Oracle не сохраняют.

**В репозитории начальная база пустая намеренно**: `hotel-open-media/index.json` отражает 0 новых гостиниц, пока нет реально подтверждённых QID. Мы не создаём вымышленных данных для красивой выдачи.

### Пример защищённого манифеста соответствий (только после проверки)

Положите на Oracle в `~/.config/jamaica-commons/verified-hotel-ids.json` файл с реальным hotel ID и реально проверенным QID. Строки ниже — **схема, не фактическое сопоставление**:

```json
{
  "schema":"jamaica.commons-hotel-identities.v1",
  "hotels":{
    "ACTUAL_HOTEL_ID":{
      "hotel_name":"EXACT_JAMAICA_HOTEL_NAME",
      "country":"Таиланд",
      "wikidata_qid":"Q_ACTUAL_VERIFIED_ITEM",
      "wikidata_country_qid":"Q869",
      "identity_reviewed":true,
      "review_reference":"https://www.wikidata.org/wiki/Q_ACTUAL_VERIFIED_ITEM",
      "reviewed_at":"YYYY-MM-DD",
      "additional_photos":[]
    }
  }
}
```

*Поле `identity_reviewed:true` выставляется только после ручного сопоставления отеля по адресу, географии и официальным источникам, а не после автоматического совпадения названия.* Если у гостиницы нет Wikidata P18, но в Commons есть реальные фотографии, можно добавить проверенные файлы в `additional_photos`: `{"file":"Exact_photo.jpg","kind":"hotel_exterior","property_photo_reviewed":true,"review_reference":"https://commons.wikimedia.org/wiki/File:Exact_photo.jpg"}`. При этом Wikidata QID и страна гостиницы должны быть подтверждены.

Команда из актуального корня Git-репозитория JAMAICA на Oracle/Lenovo (при наличии сохранённой проверенной таблицы):

```bash
python3 -B scripts/commons_open_hotel_media.py \
  --directory destination-directory.json \
  --reviewed-mapping "$HOME/.config/jamaica-commons/verified-hotel-ids.json" \
  --output-dir .
```

Посмотрите `git diff -- hotel-open-media`, проверьте реальных авторов, лицензию, URL и ID каждого отеля. Публиковать можно только `hotel-open-media/index.json` и `hotel-open-media/part-*.json` после проверки, без приватных манифестов и без ключей. Веб-сайт автоматически использует этот источник, если в индексе появились подтверждённые записи.

## С официальных сайтов гостиниц

1. Проверяйте настоящий официальный домен отеля (не рекламный портал или фишинговую копию) и его политику использования изображений.
2. Для гостей можно размещать **обычную внешнюю ссылку** на официальную галерею. Не следует использовать URL отеля как скопированную фотографию без права встраивания.
3. Если гостиница предоставляет письмо/публичные правила разрешённого использования, добавьте прямой CDN URL с доказательством разрешения в уже существующий `hotel-media-approved.json`, привязанный к точному JAMAICA hotel ID; укажите допустимые домены, источник разрешения, авторство и срок.
4. Если отель или оператор не даёт права на фотографии, оставьте заглушку и ссылку на официальную галерею (при наличии проверенного URL).

Для маршрутов/цен действует отдельное правило: опубликованная цена по прайс-листу — **не подтверждённая доступность**; включать оплату или бронирование без оператора/договора/PSP нельзя.

## Проблема `git pull` из `~/Загрузки`

`~/Загрузки` — не Git-репозиторий. Нельзя просто запускать `git pull` из этого каталога. В [HBX_EVALUATION_TEST_RU.md](HBX_EVALUATION_TEST_RU.md) теперь есть безопасная инструкция: она создаёт отдельную копию проекта в `~/Загрузки/JAMAICA_HBX_SAFE_TEST` и только затем запускает один тестовый запрос к HBX. Секреты вводятся скрыто в терминале и не публикуются.

## Юридические ограничения

Свободная лицензия разрешает повторное использование при соблюдении своих условий, но не отменяет права на неприкосновенность частной жизни, товарные знаки и отдельные ограничения фотографии архитектуры в некоторых странах. Полные права на все возможные снимки заранее гарантировать нельзя; для спорных изображений рекомендуется ручная проверка.
